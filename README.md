# 💻 CODSOFT AI INTERNSHIP PROJECTS
Welcome to my **AI Internship Projects** repository!

This repository contains the projects I developed during my Artificial Intelligence Internship. Each project demonstrates different AI concepts, problem-solving techniques, and Python programming skills. Projects included are Rule-Based Chatbot, Tic-Tac-Toe AI using the Minimax Algorithm, and a Content-Based Book Recommendation System.

# 📌 Projects Included

## 🤖 Task 1 – Rule-Based Chatbot

A simple chatbot developed using **Python** that responds to predefined user inputs using rule-based logic.

### Features
- 👋 Greets the user
- 📅 Displays current date and time
- 🪙 Coin Toss
- 🎲 Dice Roll
- 🎮 Rock-Paper-Scissors
- 🧮 Basic Calculator
- ❓ Help Menu
- 😊 Friendly conversation

---

## 🎮 Task 2 – AI Tic-Tac-Toe

An intelligent Tic-Tac-Toe game where the player competes against an AI powered by the **Minimax Algorithm**.

### Features
- 🤖 AI Opponent
- 🧠 Minimax Algorithm
- 🎮 Interactive GUI
- 🏆 Winner Detection
- 🤝 Draw Detection
- 🔄 Restart Game
- 🚫 Invalid Move Prevention

---

## 📚 Task 3 – Book Recommendation System

A content-based recommendation system that suggests similar books based on **Genre**, **Author**, and **Language**.

### Features
- 📚 Book Search
- 🤖 Content-Based Recommendations
- 📊 Similarity Scoring
- ⚠️ Error Handling
- 🗑️ Clear Button
- 💻 Interactive GUI
